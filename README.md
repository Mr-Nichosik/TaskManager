
# Tasks Manager

Simple note manager inspired by Google Keep.

## Features

- Create notes
- Edit notes
- Delete notes
- Restore deleted notes
- Delete notes forever
- Pin notes
- Mobile-first layout
- LocalStorage persistence

## Technologies

- HTML5
- CSS3
- TypeScript
- Vite
- LocalStorage
